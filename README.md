# من يوقظ الشّمس؟ — صفحة الهبوط | مسرح الخيال (الناصرة)

صفحة هبوط لمسرحية الأطفال **«من يوقظ الشّمس؟»** من إنتاج مسرح الخيال.
🗓️ الأربعاء 24.06.2026 — القصر الثقافي، الناصرة.

## المحتوى
- `index.html` — الصفحة الكاملة (صفحة واحدة، RTL).
- `tailwind.css` — ملف الأنماط (نسخة ساكنة من Tailwind بدون CDN).
- `images/` — كل الصور (البوستر، الشخصيات، صور العرض، الشعار).
- `_gen_tw.py` — سكربت توليد `tailwind.css` (اختياري، للصيانة فقط).

## النشر
الموقع **ملفات ساكنة** — بينرفع كما هو على أي استضافة ساكنة
(Netlify / Cloudflare Pages / GitHub Pages). **لا يحتاج build.**
مجلّد النشر = الجذر، والصفحة الرئيسية هي `index.html`.

## تحديث `tailwind.css`
تم توليده ليشمل **فقط** الأصناف المستخدمة + الثيم (ذهبي/جليدي/كحلي + خطوط Cairo/Tajawal).
إذا أضفت أصناف Tailwind جديدة داخل `index.html`، أعد توليده:

```bash
python _gen_tw.py
```

## قبل المشاركة على واتساب/فيسبوك
بدّل `https://your-domain.com` في وسوم `og:` و`twitter:` داخل `<head>`
بالرابط الحقيقي للموقع، حتى تظهر صورة المعاينة.
