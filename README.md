# مسرح الخيال — HTML الأصلي مع صور العرض

هذه النسخة مبنية على ملف `index.html` الأصلي نفسه، وليست إعادة تصميم.

التعديلات:
- تجميعة رئيسية من ثلاث صور حقيقية بوجوه واضحة، مع تنسيق منفصل للهاتف والكمبيوتر في `hero-montage.css` والحفاظ على العنوان والتأثيرات الأصلية.
- إضافة معرض صور متناسق مع ألوان الموقع وخطوطه، مع تكبير وتنقّل بلوحة المفاتيح.
- إضافة رابط «صور العرض» في شريط التنقّل.

الأنماط الأصلية وجافاسكريبت الأصلية لم تتغيّر. الجولة محدثة: رهط 30.9 الساعة 19:00 عرض استضافة بدون تذاكر، وشفاعمرو 16.10 الساعة 20:00 للحجز؛ خمس محطات سابقة محفوظة في قسم مستقل. أقسام القصة والشخصيات والطاقم والأرشيف محفوظة. صفحة «من يوقظ الشمس؟» ونظام المشاهدة الخاص محفوظان كما في المصدر.

## الرفع

فكّوا ضغط `elkhaial-site-github.zip` وارفعوا محتوياته إلى جذر مستودع الموقع الحالي على GitHub، بما فيها مجلد `images` وملفّا `photo-gallery.css` و`photo-gallery.js` و`hero-montage.css`. لا ترفعوا ملف ZIP نفسه بدل الملفات.

إعداد Netlify الأصلي محفوظ: مجلد النشر `.` ووظائف الخادم `netlify/functions`. إذا كان النشر مرتبطًا بالمستودع، سيبدأ بعد حفظ التغييرات. متغيرات النظام الخاصة بالمشاهدة تبقى في حساب الاستضافة؛ لم تُضَف ملفات `.env` إلى الحزمة.

للنشر عبر GitHub Pages، الصفحات العامة ساكنة، لكن نظام المشاهدة الخاص الأصلي يحتاج وظائف Netlify ولن يعمل على Pages وحده.

الصور الجديدة جرى فقط تصحيح اتجاهها وتغيير مقاسها وضغطها من الملفات الموجودة، دون أي توليد AI. الصور والبوسترات الموجودة في الأقسام الأخرى محفوظة كما في المصدر.
